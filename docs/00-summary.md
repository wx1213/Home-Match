## 一句话介绍

**HomeMatch** = 让北京的独立房产经纪人能**快速找到合作对象、谈成合作、留下信用记录**的 APP。

---

## 它解决什么问题？

北京的独立房产经纪人（不属于任何公司的"单兵"）手里有客户、也有房源，但**单个人覆盖的范围有限**：
- 我的客户要买望京的房子，但我在望京没房源 → 需要找望京的同行合作
- 我在酒仙桥有套房子要卖，但我的客户都不在那一带 → 需要找有客户的同行合作

现在的痛点：
- 找同行靠**朋友圈、微信群、线下人脉**，效率低
- 合作靠**口头约定、纸质协议**，容易扯皮
- 找的人**靠不靠谱**？只能问熟人，没法查

HomeMatch 用"**AI 智能匹配 + 顺序邀请 + 方案握手 + 双向评价**"把这个流程搬到线上。

---

## 核心流程（5 步闭环）

```
我有客户    ──→   ① 发需求     ② AI 帮我挑 5 个最合适的同行
                      ↓
我挑一个同行  ──→   ③ 发起邀请
                      ↓
同行在 24h 内点"接单"  ──→   ④ 同行 2h 内出合作方案
                      ↓
我觉得方案 OK ──→   ⑤ 确认合作，电子签名
                      ↓
合作结束    ──→   双方互评  ──→  信用分更新  ──→  下次更好匹配
```

**关键设计**：
- 每轮只邀请 1 个同行（不是"竞合"模式，避免多人抢单）
- 时间有硬约束（邀请 24h、方案 2h），逼双方快速决策
- 信用分 = 评价均分 × 活跃系数，**老赖自然被淘汰**

---

## MVP 范围（这次要做什么）

✅ **做**：
- 经纪人注册/登录（微信为主，短信备用）
- 房源录入（粘贴贝壳链接 + 手动填 + 拍实勘图加水印）
- 需求发布
- AI 智能推荐 Top 5
- 顺序邀约 + 倒计时
- 方案提交 + 电子握手
- 双向评价 + 信用分
- APP 推送（iOS + Android）

❌ **不做**（推到二期）：
- 支付、分账
- 独立聊天（用微信本身）
- 经纪公司账号
- 多城市（只做北京）
- 视频带看 / VR
- 自动调解纠纷

## 用户量与数据规模预估

- **目标用户**：北京独立房产经纪人，估计 2-3 万人
- **MVP 期内**（上线后 3 个月）：预计 100-500 真实用户，500-2000 房源
- **数据量**：房源/需求 10 万级，**PostgreSQL 完全够用，不需要 ES**

## 技术栈（用大白话讲）

### 后端（搭在地上的房子）
| 用了啥 | 大白话 | 为什么 |
| --- | --- | --- |
| **Python + FastAPI** | 写业务逻辑的"地基" | 写起来快、文档自动生成、AI 库多 |
| **PostgreSQL 15** | 存数据的"仓库" | 北京几万条房源完全够用，稳定可靠 |
| **Redis 7** | 临时小仓库（缓存、倒计时） | 快 |
| **RQ**（任务队列） | 让耗时的活（加水印、发推送）"排队慢慢做"，不卡主流程 | 轻量，比 Celery 简单 5 倍 |
| **DeepSeek-V3** + **Claude** | AI 的大脑 | 便宜+聪明的组合，便宜的干粗活（推荐），贵的干细活（评价审核） |

### APP 端（iOS + Android）
| 用了啥 | 大白话 | 为什么 |
| --- | --- | --- |
| **Flutter** | 一套代码，写两个 APP | 不用招 iOS 团队、Android 团队，一拨人搞定 |
| **Riverpod** | 管理界面状态的"大脑皮层" | Flutter 官方推荐 |
| **Hive** | APP 本地存点东西（缓存上次列表） | 弱网/断网时还能看到上次的数据 |
| **Firebase 推送** | 苹果/安卓的"通知中心" | 行业标准，免费 |

### 后台（运营人员用的网页）
- **Vue 3** + **Element Plus**：标准的"管理后台"技术栈，运营审核账号、看数据用

### 第三方服务（花钱买的）
- **阿里云 OSS**：存图片（实勘图、头像）
- **阿里云短信**：发验证码
- **DeepSeek API**：AI 推理（一个月 3000 块预算）
- **Firebase**：推送通道

## 数据模型（10 张表）

简单说就这几类东西：
1. **users**：经纪人（手机号加密、微信 unionid、信用分）
2. **properties**：房源（小区、户型、价格、图片、状态）
3. **demands**：需求（区域、价格区间、户型、看房时间）
4. **invitations**：邀请（谁邀请谁、24h 倒计时、状态）
5. **proposals**：合作方案
6. **cooperations**：合作主记录
7. **reviews**：评价
8. **devices**：推送设备（FCM token）
9. **app_versions**：APP 版本管理
10. **event_logs**：用户行为日志

## 用户体验设计（"主流 APP"感的关键）

这块专门写了 [04-ui-ux-guidelines.md](04-ui-ux-guidelines.md)，重点说几条：

| 要做到的 | 怎么做到 |
| --- | --- |
| **看着像"正规大厂的 APP"** | 颜色字体有规范、按钮大小统一、有骨架屏和加载动画 |
| **点哪哪响应** | 任何按钮按下立刻有视觉反馈（< 100ms） |
| **网络断了不慌** | 列表先显示上次缓存 + 顶部"网络已断开"提示 |
| **错误提示人话** | 不说 "ERROR 500"，说 "开小差了，稍后再试" |
| **暗色模式** | 自动跟随系统，不刺眼 |
| **APP 启动快** | 冷启动 < 2 秒 |

## 关键风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| **公司主体 / 备案号还没办** | 阻塞 App Store 上线 | **MVP 阶段用开发模式验证**（模拟器+测试号），上线流程并行启动（[D-021](00-decisions.md#d-021)） |
| **微信开放平台审核慢** | 阻塞正式微信登录 | 用"微信开发者测试号"先跑功能，资质到位后只换 AppID，**代码不动** |
| **贝壳链接解析有法律/技术风险** | 反爬严 | **MVP 阶段只让用户复制粘贴链接**，不做自动解析，URL 存起来就行 |
| **LLM 调用可能很贵** | 月成本失控 | 设了 ¥2000 软告警 / ¥5000 硬上限，超过就自动降级到规则匹配 |
| **敏感信息泄露** | 合规问题 | 手机号 AES-256 加密存，密钥不进数据库，握手前不暴露真实姓名电话 |

## 里程碑（4 个阶段，估时）

| 阶段 | 产出 | 估时 |
| --- | --- | --- |
| **M1 - 后端能跑** | FastAPI 起服务 + 10 张表建好 + 用户/房源/需求 CRUD + Swagger 可测 | 1-2 周 |
| **M2 - 核心流程跑通** | 邀约 + 方案 + 握手 + 评价 + 信用分 + 推送，全在 API 层跑通 | 2-3 周 |
| **M3 - APP 能用** | Flutter APP 6 个核心页面 + 微信登录 + 推荐页 + 合作看板 | 3-4 周 |
| **M4 - 上线准备** | UI 打磨 + 兼容性测试 + 业务资质申请 + 内部灰度 | 4-6 周 |

> **总周期**：3-4 个月 MVP 完整跑通 + 灰度测试。**但 M1 + M2 完成后（2-4 周）**就可以用 Swagger + 模拟器验证核心撮合逻辑，业务侧能给你看到流程。

## 开发环境需要啥

**后端**（Mac/Linux 都行）：
- Python 3.11+
- PostgreSQL 15（本地装或 Docker 起）
- Redis 7（同上）
- 装包工具：`uv`（比 pip 快 10 倍的现代工具）

**APP 端**：
- Flutter SDK 3.x
- iOS Simulator（Mac 自带，免费）
- Android Studio（自带模拟器，免费）
- 微信开发者工具（微信测试号扫码用）

**全部本地能搞定，不依赖任何线上服务**就能把核心功能跑起来。

## 立即可做的事

如果你看完 OK，我们可以**马上开干**：

1. **后端骨架**（30 分钟）：
   - `uv init` 起项目
   - 装 FastAPI / SQLAlchemy / Alembic
   - 起 PostgreSQL + Redis（Docker 一行命令）
   - 跑通第一个接口 `GET /health`

2. **数据库初始化**（1 小时）：
   - 写 10 张表的 SQL
   - Alembic 第一次迁移
   - 用 seed 脚本造 10 个测试房源、5 个测试用户

3. **第一个业务流程**（1-2 天）：
   - 注册 / 登录（先短信版，微信后面加）
   - 发布需求
   - 手动指定 Top 5（先用最简单的规则排序，AI 后面再上）
   - 跑通邀请→接单→方案→握手→评价 全流程

**4 周内**能让你在 Swagger UI 上点几下，把整个撮合流程走一遍，看到数据落库。

App Store 上线、华为小米 OPPO vivo 商店审核、软著申请 等业务资质的事**可以并行启动**，我们这边开发继续。
